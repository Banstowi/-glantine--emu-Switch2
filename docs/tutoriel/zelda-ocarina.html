Première installation de l'émulateur ? Suivez d'abord le tutoriel d'installation.

1Vérifier que le jeu est prêt

  1. Ocarina of Time apparaît dans la liste des jeux d'Erable (voir Ajouter vos jeux).
  2. Faites un clic droit sur le jeu → Configure Game.
Tous les réglages ci-dessous se font dans cette fenêtre, et ne concernent qu'Ocarina of Time : vos autres jeux gardent leurs réglages. Le jeu doit être fermé.

2Installer le mod de shaders

Le mod ootrshaders limite les saccades : moins de shaders à préparer pendant que vous jouez.

  1. Onglet Add-Ons → Import Mod from ZIP.
  2. Choisissez ootrshaders.zip, puis le type RomFS.
  3. Vérifiez que ootrshaders est coché, puis Apply.
Max Resolution et Dynamic FPS sont déjà inclus dans Erable : laissez-les cochés.
Ne prenez ce zip qu'auprès d'une personne de confiance, et analysez-le avec Microsoft Defender avant de l'importer. Un mod de shaders ne contient jamais de .exe.

3Augmenter la mémoire émulée

  1. Onglet System, partie Core.
  2. Memory Layout : 6GB DRAM ou 8GB DRAM.
  3. Apply.
Choisissez 8GB seulement si votre PC a au moins 16 Go de mémoire vive, et 6GB s'il en a 12 Go. Sinon, laissez 4GB DRAM (Default) : le PC ralentirait au lieu d'accélérer. Pour connaître votre mémoire : Ctrl + Maj + Échap → Performance → Mémoire.

4Choisir Vulkan et votre carte graphique

  1. Onglet Graphics.
  2. API : Vulkan.
  3. Device : votre carte graphique (NVIDIA GeForce ou AMD Radeon), pas la puce graphique intégrée au processeur.
  4. Resolution : 1X (720p/1080p).

5Activer le DLSS

Ocarina of Time agrandit son image avec son propre réseau « DLSS ». Selon votre carte :

  1. Carte NVIDIA (GeForce RTX) : cochez Use NVIDIA DLSS in place of a game's DLSS. La ligne Ready doit apparaître en vert ; sinon, ouvrez l'application NVIDIA pour qu'elle télécharge les fichiers DLSS, puis rouvrez cette fenêtre.
  2. Autre carte (AMD, Intel) : cochez Use the game's own DLSS.
  3. Apply, puis OK.
Le DLSS NVIDIA remplace celui du jeu uniquement en résolution 1X : gardez Resolution sur 1X, le DLSS se charge d'agrandir l'image.

6Précompiler les shaders

Au premier lancement du jeu, Erable propose de préparer les shaders avant de jouer, ce qui évite la plupart des saccades de la première partie.

  1. Lancez le jeu, puis choisissez Précompiler maintenant.
  2. Patientez quelques minutes : le jeu démarre tout seul à la fin.
Cette étape n'a lieu qu'une fois. Elle recommence seulement après une mise à jour du pilote de la carte graphique.

7Reprendre le cache d'un autre PC

Si quelqu'un de la famille a déjà joué, son cache de shaders évite presque toutes les saccades sur un autre PC.

  1. Sur le PC qui a déjà joué : clic droit sur le jeu → Ouvrir le cache de pipelines transférable.
  2. Fermez Erable, puis copiez le dossier 0400486024dec000 sur une clé USB.
  3. Sur l'autre PC : ouvrez le même emplacement de la même façon, fermez Erable, puis collez-y le dossier en remplaçant celui qui existe.
Gardez ce dossier dans la famille : il contient des éléments du jeu et ne doit pas être publié sur Internet.

✓Et ensuite ?

Lancez le jeu. Les premières minutes, et à chaque nouvelle zone, quelques saccades restent normales le temps que l'émulateur prépare les shaders ; elles disparaissent ensuite. Ne videz pas le cache de shaders entre deux parties.

Un souci ? Clic droit sur le jeu → Rapport de compatibilité… → Envoyer par e-mail.
